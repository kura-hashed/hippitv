# HippiTV 🦛
### Healthy, Low-Stimulation English Learning Video Platform for Babies & Toddlers

**HippiTV** is a Netflix / Apple TV style streaming platform designed for parents raising young children learning English. It features **480+ curated, low-stimulation, developmentally-sound videos and animated stories** with age-specific filters (0-1 yr, 2 years, 3 years, 4 years, 5+ years).

---

## ✨ Key Features

1. **Age-Based Content Filtering**:
   - 🍼 **0 - 1 Year (Infant)**: Sound recognition, parentese babbling, acoustic lullabies, high-contrast visual books.
   - 🧸 **2 Years Baby (Toddler)**: First 50 words, gesture mimicry, slow-paced human speech (Ms. Rachel, Super Simple Songs), board books, sensory water play.
   - 🎨 **3 Years Baby (Preschool)**: 2-3 word sentences, emotional regulation (Daniel Tiger, Bluey), interactive pretend kitchen play, Khan Academy Kids.
   - 🧩 **4 Years (Pre-K)**: Phonics blending (Alphablocks), number sense (Numberblocks), rhyming books (Pete the Cat), scavenger hunts.
   - 🚀 **5+ Years (Early Primary)**: Graded readers (Oxford Owl), science exploration (Octonauts), sight words & storytelling.

2. **Healthy Pacing & Low-Stimulation Standards**:
   - Filter by **🌿 Low-Stimulation / Calm**, **☁️ Gentle Pacing**, and **🎈 Interactive Movement**.
   - Based on American Academy of Pediatrics (AAP) and Speech-Language Pathologist guidelines to prevent digital sensory overload and post-screen meltdowns.

3. **Parent Co-Viewing Prompts & Actionable Tips**:
   - Every piece of content features a **"Why Speech Therapists Love It"** breakdown.
   - Actionable dialogue scripts for parents: exactly what to say, point to, and mimic in real life.
   - Target English vocabulary spotlight for each resource.

4. **Interactive Parent Tools**:
   - 🧠 **Speech Milestones by Age**: Checklist of typical expressive/receptive milestones and everyday household phrases.
   - 🛡️ **Screen-Time & Stimulation Guide**: Comparison of gentle vs hyper-stimulating media.
   - 📅 **Daily English Routine Template**: Interactive checklist balancing acoustic morning songs, tactile play, gentle shows, and screen-free bedtime books.
   - 💖 **Saved Playlist (Favorites)**: Bookmark favorites for quick daily access, stored in `localStorage`.
   - 🔍 **Real-time Search**: Search across titles, creators, tags, and vocabulary.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ or v20+)
- npm

### Development
```bash
# Install dependencies
npm install

# Start local dev server
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
npm run preview
```

## 🛠️ Technology Stack
- **Framework**: React 18 + Vite
